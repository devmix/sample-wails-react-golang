# Project Structure


## Key Paths

| Path | Purpose |
|------|---------|
| `main.go` | Entry point: wires DB → repos → services → Wails app |
| `internal/app/service/` | Business logic, registered as Wails services |
| `internal/pkg/repository/` | Raw SQL, migrations, DB connection |
| `frontend/bindings/` | Auto-generated by Wails vite plugin — never edit manually |
| `$XDG_DATA_HOME/sample-wails-react-golang/app.db` | SQLite database location (not in project dir) |
